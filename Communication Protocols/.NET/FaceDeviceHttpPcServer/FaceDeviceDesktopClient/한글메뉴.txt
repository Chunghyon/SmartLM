참고 : 괄호 안은 기존의 영어 이름
1. Main Tab 구성
환경설정, 단말기, 사용자, 출입조회

(1) 환경설정 (Dashboard)
시스템현황 : 단말기 수, 사용자 수 및 이벤트 수 요약

(2) 단말기 (Device Management)
1) 추가 (Device Discovery) : 검색 (Auto Search), 등록(Install Device)
2) 관리 (Installed Devices - Management) : 제거(Remove Device) , 하단에  등록된 단말기 리스팅, 더블클릭시 단말기제어 상세메뉴 팝업
[1] 제거 버튼 누르면 선택된 단말기 제거
[2] 단말기 리스팅 칼럼 : 순번(No.), 선택(Selected), 단말기명(Door), 위치(Tag Name), 시리얼넘버(SN), IP, Status
[3] 단말기제어 상세메뉴 내용
1] 단말기명 : 현재의 단말기명, 수정 가능
2] 위치 : 현재의 위치 정보, 수정 가능
3] 출입자할당 : 출입 가능한 사용자명 및 사용자번호, 추가/제거 가능
4] 업로드 : 해당 단말기에 할당된 사용자 정보를 단말기로 전송 보냄, 전송 후, 결과 성공/실패 표시
5] 다운로드 : 해당 단말기로부터 사용자 정보를 전송 받음. 전송 후, 결과 성공/실패 표시
6] 초기화 (Initialization): 해당 단말기 정보를 모두 초기화

(3) 사용자 (Personnel) : 상단에는 추가(Add Personnel), 제거, 수정 버튼이 있고, 하단에는 현 사용자 리스트 나타남.
1) 추가(Add Personnel)
[1] 사용자명(Name) : 사용자 이름
[2] 사용자번호(User ID) : 10001~999999 까지 할당 가능, ACS에서는 Worker No.로 표기됨.
[3] 사진등록 : 현 PC에 있는 얼굴 사진 등록
[4] 패스워드 : 사용자의 출입 비밀번호
[5] 단말기할당 : 이 사용자가 출입 가능한 단말기 현황, 추가/제거 가능. 복수의단말기에 할당 가능. 추가/제거 시 해당 단말기로 정보 전송 버튼 추가.
2) 제거 : 선택된 사용자 제거. 제거 시, 제거된 사용자의 출입이 허용된 단말기에 정보 전송 버튼 추가
3) 수정 : 추가 화면과 동일한 화면. 수정 가능
4) 사용자 리스트의 칼럼 : 사용자명, 사용자번호, 사진등록, 패스워드, 할당된단말기수
[0] 순번 : 현 리스트의 순번.
[1] 선택 : 제거 또는 수정을 위한 선택, 더블클릭시 수정화면
[2] 사용자명(Name) : 사용자 이름
[3] 사용자번호(User ID) : 10001~999999 까지 할당 가능, ACS에서는 Worker No.로 표기됨.
[4] 사진등록 : 사진 등록 여부 Y/N으로 표기
[5] 패스워드 : 사용자의 출입 비밀번호. ****로 표시
[6] 단말기할당 : 할당된 단말기 개수

(4) 출입조회(Attendance)
사용자명 또는 사용자번호 또는 단말기명으로 조회(Search)
시작시간 및 종료시간 설정하여 조회{Search)
실시간 버튼 누를 경우 실시간 이벤트 창을 띄워 종료 버튼 누를 때까지 실시간 이벤트 표시
