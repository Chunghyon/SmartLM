# 로그 통일 변경사항

## 목적
"저장 및 선택한 단말기로 전송" 동작 확인을 위한 로그를 **서버 콘솔 한 곳에 통합**하여, 전체 프로세스를 한눈에 파악할 수 있도록 개선

## 변경 내용

### 1. 클라이언트 측 로그 제거 (FaceDeviceDesktopClient/PersonForm.cs)
- ? **제거**: `DebugLogForm` 디버그 창 로그 출력 모두 제거
- ? **유지**: 사용자에게 보여지는 `MessageBox` 알림은 유지
- ? **추가**: 성공 메시지에 "서버 콘솔에서 전송 과정을 확인할 수 있습니다" 안내 추가

### 2. 서버 측 로그 통합 및 간소화 (Program.cs)

#### ?? 전송 요청 단계
```
?? [클라이언트 요청] 단말기 {SN}에 사용자 전송 요청 → 대기 중인 사용자: {count}명
```

#### ?? Keepalive 단계
```
?? Keepalive 수신: 단말기 {SN} (IP: {IP})
?? Keepalive 응답: 단말기 {SN}에 AddPeople={count} 전송 → 사용자 다운로드 대기 중
```

#### ?? 다운로드 단계
```
?? 다운로드 요청: 단말기 {SN}가 사용자 목록 요청
?? 다운로드 응답: 단말기 {SN}에 {count}명의 사용자 정보 전송
   샘플: UserID={ID}, 이름={Name}, 사진={PhotoLen}bytes
```

#### ? 완료 단계
```
? 다운로드 성공: 단말기 {SN}에 {count}명 정상 저장 완료!
```

또는 실패 시:
```
? 다운로드 결과: 단말기 {SN} - 성공 {success}명, 실패 {fail}명
   실패: UserID={ID}, 에러={message}
```

### 3. 불필요한 로그 제거
- ? JSON 응답 미리보기 로그 제거 (500자 이상의 긴 로그)
- ? `[DOWNLOAD TRACE]`, `[KEEPALIVE TRACE]`, `[PUSH TRACE]` 등 중복 영어 태그 제거
- ? 저장소(StateStore) 내부 동작 로그 제거

## 사용 방법

### 1. 사용자 추가/수정 시
1. FDDC에서 사용자 정보 입력
2. "저장 및 선택한 단말기로 전송" 클릭
3. **서버 콘솔창**에서 전체 프로세스 확인:
   - ?? 전송 요청
   - ?? Keepalive
   - ???? 다운로드
   - ? 완료

### 2. 실시간 모니터링
- 서버 콘솔창만 보면 모든 통신 과정이 시간순으로 표시됨
- 각 단계별 이모지(??????????)로 구분되어 한눈에 파악 가능

## 주요 개선점
1. ? **단일 로그 출력**: 서버 콘솔 하나만 확인하면 됨
2. ? **간결한 메시지**: 중복 제거, 핵심 정보만 표시
3. ? **한글 메시지**: 이해하기 쉬운 한국어 로그
4. ? **시각적 구분**: 이모지로 각 단계 명확히 구분
5. ? **불필요한 로그 제거**: JSON 미리보기, 내부 동작 로그 등 제거
