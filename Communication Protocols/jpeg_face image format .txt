### ✅ Formats Supported by Hardware Decoding

| Parameter | Verified Compatibility Range |
|---|---|
| Encoding Method | **Baseline JPEG** (non-progressive) |
| Color Format | **YUV 3-plane** (4:4:4, 4:2:2, or 4:2:0 all supported) |
| MCU Alignment | 16-pixel alignment or non-alignment both supported |
| Dimensions (Odd/Even) | Odd-numbered pixel dimensions supported |
| Dimensions (Range) | Approximately **256 × 256 to 720 × 720** |
| Huffman Table | Must be **standard Huffman** (default tables from JPEG spec Annex K) |
| Metadata | Standard JFIF/APP0 supported |


## Mandatory Requirements for Server-Side Colleagues

Please generate or transcode face images (JPEG) sent to the device according to the specifications below; otherwise, hardware decoding on the device will fail:

### 1. Encoding Method
- **Must be Baseline**: Disable `progressive` mode.
- **Must use Standard Huffman**: Disable `optimize` and `arithmetic coding`.

### 2. Color Format
- **Must be 3-channel YCbCr** (do not send grayscale images, even if the source is monochrome).
- 4:2:0, 4:2:2, and 4:4:4 are all supported; **4:2:0** is recommended (best compatibility and smallest file size).

### 3. Dimensions
- **Width × Height** should ideally fall within the **`[256, 720]`** range.
- The maximum decoding size initialized by the device-side decoder is **1024×1024**; do not equal or exceed this value.
- **Aspect Ratio** should not exceed **3:1** (avoid excessively long and narrow images).
- Recommended dimensions: `448×592`, `450×600`, `640×640`. ### 4. Metadata
- **Remove ICC profile**: Many raw photos from phones/cameras contain ICC profiles; these need to be stripped.
- **Remove large EXIF ​​blocks** (GPS / Thumbnail / Maker Notes); retaining standard EXIF ​​(<4KB) is generally fine.
- Retaining standard JFIF/APP0 markers is sufficient.

### 5. Recommended Parameters

**Python (Pillow)** — Most common server-side environment:

```python
from PIL import Image

img = Image.open(src_path).convert("RGB")  # Force 3 channels, remove ICC
img.save(
dst_path,
format="JPEG",
quality=85,            # 80–90 is acceptable; avoid ≥95 (which triggers optimization)
optimize=False,        # ⚠️ Critical: Must be disabled; otherwise, Huffman tables are customized
progressive=False,     # ⚠️ Critical: Must be disabled
subsampling=2,         # 4:2:0
exif=b"",              # Clear EXIF
icc_profile=None,      # Clear ICC
)
```

**ImageMagick / convert**:

```bash
convert input.jpg \
-strip                     # Remove all extra blocks (EXIF/ICC/XMP, etc.)
-interlace none            # Disable progressive mode
-sampling-factor 4:2:0 \
-quality 85 \
-define jpeg:optimize-coding=false \
output.jpg
```

**libjpeg-turbo (C)**: Use default configuration; do not call `jpeg_set_optimize_coding(&cinfo, TRUE)` and do not call `jpeg_simple_progression()`.
