# Local docking device usage instructions

1、Open local sample

Find the local docking device folder of Door.Access.TCPClient.Example. and open the Example

![image-20231024101743208](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20231024101743208.png)

2、Fill in device parameters

Find the CommandAllocater.java class in the access package, and fill in the device information in the getTcpCommandDetail method under the CommandAllocater.java class

![image-20231024102002430](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20231024102002430.png)

3、Running example

After completing the other steps, you can run the example.

![image-20231024102119273](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20231024102119273.png)

After the example is started, remote door opening, card number addition, and card number reading instructions will be executed immediately
